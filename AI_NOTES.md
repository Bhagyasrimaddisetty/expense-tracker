# AI Usage Notes

## AI Tools Used

I used ChatGPT during development to:

- Generate the initial Spring Boot project structure
- Design the REST API endpoints
- Generate repository, service, and controller templates
- Assist with validation annotations
- Generate Swagger/OpenAPI configuration
- Help create unit test templates
- Draft the README documentation

## What I Validated

- Verified all endpoints using Swagger UI.
- Tested add, view, filter, total, and delete operations.
- Fixed compilation errors and package issues.
- Ensured the project builds successfully using Maven.

## Changes Made

- Updated package names to match the project.
- Added input validation.
- Improved the project structure.
- Added Swagger documentation.
- Added unit tests.

## AI Suggestions Not Used

Initially, AI suggested using a database such as MySQL. I chose an in-memory data structure because the assignment explicitly stated that a database was not required.
